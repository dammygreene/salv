# CULLER - Visual Design System

## Art direction
`Cyber Chrome Y2K Utility`

CULLER should feel like a real piece of futuristic consumer software from a parallel 2003, rebuilt with modern web technology and connected to Solana.

The design should be recognizable without looking like a crypto template.

## Mood
- industrial
- cold
- polished
- strange
- playful
- technical
- useful
- slightly rebellious

## Color system
Do not make the UI rainbow.

Primary surfaces:
- black
- near-black
- graphite
- gunmetal
- brushed silver
- pale gray

Accent family:
- icy blue
- electric cyan used sparingly

Status:
- green for recovered/success
- amber for watch/review
- red for destructive/error states

The accent colors should not dominate the whole screen.

## Material language
Use:
- brushed metal gradients
- soft reflections
- subtle bevels
- inset borders
- translucent glass layers
- thin technical lines
- controlled glow
- tiny spec labels

Do not use:
- giant glass blobs
- fake 3D chrome text everywhere
- excessive reflections
- chrome behind every button
- neon outlines around everything

## Layout
Desktop:
- dense but breathable
- max content width around 1400px
- strong visual center
- modular panels

Mobile:
- single column
- sticky primary action
- cards become stacked modules
- no horizontal data tables

## Hero
Hero should be an interactive `CULLER MACHINE`.

Main hierarchy:
1. brand
2. blunt message
3. wallet/address input or connect button
4. machine visualization
5. one clear CTA

Suggested copy:
`YOUR WALLET HAS LEFTOVERS.`
`LET'S SEE WHAT THEY ARE.`

## Buttons
Primary button:
- silver/chrome body
- dark text
- strong bevel
- clear hover state

Secondary:
- translucent dark body
- fine silver border

Destructive:
- red status only where necessary

Buttons should look like physical controls, not generic rounded app pills.

## Cards
Cards resemble compact hardware modules.

Use:
- title row
- tiny metadata
- large value
- action area
- status indicator

## Iconography
Use simple geometric icons.
Prefer custom SVG marks for key actions:
- scan
- cull
- watch
- recover
- burn
- history
- rewards

Avoid emoji in the actual product UI except where deliberately used as a small accent.

## Texture
Very subtle noise and scanlines are allowed.
They must not reduce readability or create accessibility problems.

## Motion
Motion should reinforce state changes:
- scan progress
- asset discovery
- cull confirmation
- reward increment
- tab transitions

Use fast motion for UI feedback, slower motion only for the hero atmosphere.

Respect `prefers-reduced-motion`.

## Branding
Wordmark:
`CULLER`

Logo direction:
- strong geometric wordmark
- simple cull/recovery symbol
- avoid literal recycling iconography

Potential visual symbol: a broken/partial circular arrow combined with a hardware port or extraction mark.

## Typography
Display:
- Space Grotesk or similarly geometric sans.

Technical:
- IBM Plex Mono or JetBrains Mono.

Body:
- modern neutral sans.

Do not use futuristic fonts for every label.

## Visual anti-patterns
Reject anything that looks like:
- generic AI dashboard
- crypto casino
- NFT mint website
- cyberpunk game menu
- low-effort Y2K nostalgia site
